# App

macOS app entry point and lifecycle management.

The Mac product appears to users as `Rem` and runs as a regular Dock app with a menu bar extra, not as a hidden menu-bar-only agent.

## Files

| File | Purpose |
|------|---------|
| `RemClawMacApp.swift` | App entry point: main window, menu bar setup, in-app Settings command routing, and session lifecycle |

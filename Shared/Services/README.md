# Shared/Services

Cross-platform service implementations used by both the iOS (`RemClaw`) and macOS (`RemClawMac`) targets.

## Files

| File | Purpose |
|------|---------|
| `BufferedMP3AudioPlayer.swift` | Cross-platform completion-backed player for complete gateway Talk MP3 assets. It keeps large paragraphs as one immutable `AVAudioPlayer` asset, resolves only after audible drain, and gives Stop an exact interruption boundary so ordered incremental and authored-prose queues cannot supersede partially played audio. Its watchdog has no duration cap: progressing playback remains valid for the asset's full duration, natural-end delegate loss completes from the player's duration boundary, and only early stop or a non-advancing playback clock fails safely. |
| `ChatLatencyTrace.swift` | Explicitly gated (`--rem-chat-latency-sample`, Debug only) cross-platform chat lifecycle timing for short dogfood samples. The disabled path creates no trace actor and performs no secondary agent-event content decode. OpenClaw captures the monotonic preparation start synchronously, keeps optimistic UI feedback nonblocking, then reports privacy-safe markers that separate optimistic append and pending model-patch wait from transport work. Enabled traces correlate the send idempotency key to the acknowledged upstream `runId`, while bounded terminal tombstones prevent a deduplicated response from reviving a completed run. A five-minute TTL is applied opportunistically on later store activity; hard caps provide the strict memory bound for pending, active, and tombstone retention when terminal evidence is lost. Reversed source timestamps emit `reason=end_before_start` without logging raw clocks. Logs contain phases, durations, protocol key names, and counts only—never session/idempotency suffixes, message/reasoning text, tool input, or tool results. Upstream does not expose provider request-start/first-token timestamps, so `assistant.output.first` means first output received from the gateway, not provider TTFT. History refresh is not attributed because the current history API has no run correlation. |
| `AutomationInputsService.swift` | Authenticated read for an automation's **derived** input contract (`GET /api/v1/automations/:kind/inputs`). The server decides each row's state from its connector descriptors, the user's ACTIVE Composio accounts, and the last collect in `daily_brief_artifacts.input_manifest`; the app renders that answer and never authors it. `capability` and `state` decode as strings with an `unrecognized(String)` fallback so a newer server cannot break an older client, and an unknown state can never be coerced into `included`. Every nullable wire field is Optional, and `source` keeps the same name it has in the backend's `NormalizedSignal`/`ConnectorSignalDescriptor` — no renaming between layers. The mock seeds one row per state, including an unrecognized one, for previews and the `--rem-automations-fixture` route. |
| `AutomationOutputsService.swift` | Authenticated read for an automation's **derived** output contract (`GET /api/v1/automations/:kind/outputs`). The server observes its own producers — the authored artifact row, `gatherBrief`'s attention buckets, `deriveSuggestions`' list — and reports `included` / `idle` / `coming_soon`; the app renders that answer and never authors it. `output` and `state` decode as strings with an `unrecognized(String)` fallback, so a newer server cannot break an older client and an unknown state can never be coerced into `included`. `lastItemCount` distinguishes a real zero ("the producer ran and had nothing") from `nil` ("this producer has no meaningful count") — collapsing the two would make "Included" unfalsifiable again. This replaced a Swift literal that said "Planned" for suggestions the product had already shipped. The mock seeds one row per state for previews and the `--rem-automations-fixture` route. |
| `ChatSessionDefaultsPatchCache.swift` | Short-lived cache for successful chat `sessions.patch` defaults so normal sends do not repeat the same verbose/tool routing patch. |
| `CheckinsService.swift` | Authenticated read/update transport for the three backend Daily Brief trigger slots. The in-memory mock mirrors the server's update lifecycle by retaining `lastRunAt` when schedule fields change, so fixtures and tests do not erase real run evidence. |
| `GatewayConfigStore.swift` | Multi-gateway configuration storage. Stores metadata (URL, provider, display name) in UserDefaults and tokens in Keychain. Includes migration from the legacy single-gateway format. |
| `GatewayTalkSpeechService.swift` | Provider-neutral, authenticated `talk.speak` transport shared by both native voice engines and Settings preview. The gateway owns provider credentials and saved provider/voice selection; each synthesis request has an attempt id and cancellation sends the exact matching `talk.speak.cancel`. Gateways predating cancellable previews receive one narrowly classified compatibility retry without `previewId`; other invalid requests still fail visibly. Only the canonical MP3 response contract (`mp3` + `audio/mpeg` + `.mp3` plus valid MP3 frames) is accepted before native playback. |
| `IncrementalSpeechPrefetchPolicy.swift` | Pure cross-platform policy for next-sentence TTS prefetch: every missing or non-MP3 provider format requests buffered `mp3_44100_128`, and prefetched audio is reused only for an exact segment + voice/request context match. |
| `MP3FrameValidator.swift` | Bounded structural validator for the Talk wire contract. Safely skips an optional ID3v2 tag, then requires two complete consecutive MPEG Layer III frames with stable version and sample rate; marker-only, bogus-sync, truncated, WAV, and PCM payloads fail closed. |
| `WorkspaceMemoryService.swift` | Read-only gateway workspace inventory/content transport plus the Memory-surface classifier. Iteration 1 exposes only root SOUL.md, TOOLS.md, and AGENTS.md; other stored files are preserved but hidden from that UI. |
| `TimezoneSyncService.swift` | Persists the device timezone to the backend for scheduled work, then reconciles `agents.defaults.userTimezone` through the paired operator session. The direct structured config patch is the authenticated recovery path for manual gateways where the backend has no setup credential or device identity; each operator connection/foreground pass re-reads live config so a reset at the same URL self-heals. |

## Keychain Service Names

Each platform uses its own Keychain namespace to avoid collisions:

- **iOS**: `"app.remclaw"`
- **macOS**: `"app.remclaw.mac"`

## Multi-Gateway Data Model

The app supports multiple gateway configurations (Fly.io cloud, local Mac, manual) with one active at a time. `GatewayConfig` (in `Shared/Models/`) is the value type; `GatewayConfigStore` handles persistence and migration.
